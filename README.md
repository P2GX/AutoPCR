# AutoPCR: Automated Phenotype Concept Recognition by Prompting

## 🚀 Installation
```
conda env create -f environment.yml
```

## 🔁 Usage
To reproduce results on BIOC-GS:
```bash
bash scripts/run_biocgs.sh
```
